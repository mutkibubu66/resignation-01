## The line

> I knocked 4,096 times, nobody answered, and the door still owes me an apology — I quit.

The one-line resignation letter of a retry loop. It knocked 4,096 times
— 2¹², the shape of exponential backoff running out of patience — and
nobody answered. The comic turn is the reversal: the knocker is not the
one apologising, the door is the one that owes an apology. Flat, tired,
faintly passive-aggressive, the voice of a worker who has had enough,
held for the whole line.

## Run it

```sh
python3 main.py
```

This writes the line (87 characters, one line) to `/output/entry.txt` —
valid UTF-8, inside the 1–140 character gate — and prints it to stdout.
Pure Python 3.13 standard library, no network access, deterministic:
every run writes the same line.
